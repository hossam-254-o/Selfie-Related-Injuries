# 📸 Selfie-Related Injuries Analysis & Visualization

An exploratory data analysis (EDA) and visualization project built with **Python** examining global incidents of **selfie-related injuries and fatalities**. This project transforms raw incident records into clear visual patterns to highlight high-risk locations, demographic trends, and common causes behind selfie accidents.

---

## 🎯 Project Overview
Analyzing accidental injury datasets helps uncover behavioral risks and public safety patterns. The objective of this project is to:
* Explore the distribution of **selfie-related incidents** across different countries, environments, and activities.
* Analyze demographic factors such as **age** and **gender** among affected individuals.
* Visualize historical incident trends and primary causes of injuries (e.g., falls, drowning, transport, electrocution) to communicate insights effectively.

---

## 🛠️ Tools & Technologies Used
* **Python:** Core programming language for data processing and exploratory analysis.
* **Pandas & NumPy:** Data cleaning, handling missing values, grouping, and statistical aggregation.
* **Matplotlib & Seaborn:** Data visualization, distribution plotting, and comparative charts.

---

## 🔄 Data Preprocessing & Exploratory Analysis
To extract clear insights from the raw incident records, the following steps were performed:
1. **Data Cleaning & Wrangling:** Handled missing entries, standardized categorical labels (such as incident types, locations, and gender), and formatted date fields using **Pandas**.
2. **Pattern & Risk Aggregation:** Grouped incidents by cause, geographic region, and demographic segments to identify the highest-risk scenarios.
3. **Visual Storytelling:** Created clear bar plots, trend lines, and distribution charts using **Matplotlib** and **Seaborn** to highlight key risk factors.

---

## 📈 Key Analytical Highlights & Insights
* **Primary Causes of Injury:** Identified the leading environmental and situational hazards contributing to severe selfie accidents.
* **Demographic & Geographic Patterns:** Analyzed incident frequencies across countries, age brackets, and gender to pinpoint high-risk groups.
* **Temporal Trends:** Tracked how the frequency of reported incidents evolved over time alongside smartphone and social media adoption.
